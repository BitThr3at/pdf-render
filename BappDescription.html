This extension renders downloadable file bodies directly within HTTP responses. When a response contains a document or a spreadsheet, it is displayed in a dedicated tab, making it easy to inspect content without leaving the Burp Suite interface.

Features

  • Automatically detects and renders PDF, XLSX, XLS, CSV and TSV bodies in HTTP responses
  • Detection works on magic bytes, and expands gzip/deflate encoded bodies before sniffing them
  • PDF viewing with page navigation, zoom, fit, rotation, text selection, find, thumbnails and bookmarks, on a toolbar that follows the active Burp theme
  • Spreadsheets open in a sortable, filterable grid with one tab per sheet and the source row numbers kept in view
  • Shows the filename, type and size of the served file, and can save the body to disk
  • Read-only by design: annotation and form editing are disabled, and parsing is capped to protect Burp against hostile files
  • Spreadsheet support adds no third-party libraries, so the extension stays the same size as the PDF-only version

Usage

  1. Browse or intercept traffic containing file downloads.
  2. Select a response containing a PDF or spreadsheet.
  3. Navigate to the custom tab in the response viewer to see the rendered document.

Notes

Formulas are not evaluated; the value cached alongside the formula by the producing application is shown. Legacy .xls support covers the common cell records, and password-protected workbooks are reported rather than partially parsed.
